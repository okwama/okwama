## 💼 Featured Work

### 💳 [Orbit](https://www.orbit247.co.ke/) · *CIT Logistics Systems*
Multi-tenant payments platform on Azure, plus an Android POS app for card terminals.
- Built payment flows that route card and M-Pesa through DPO, and bank-to-bank "Lipa na Bank" over PesaLink using ISO 20022 messaging
- Implemented split payments, dual receipt printing and resilient status polling with exponential backoff on POS terminals
- Debugged and stabilised production microservices: auth service failures, DI registration across 10 services, and Azure Firewall networking

`Azure` `Microservices` `Kotlin` `Android POS` `PesaLink` `ISO 20022`

### 🏥 [Hawa Health CMS](https://hawa.health/)
Modular clinical management system for private clinics in Kenya, part of a privacy-first women's health platform.
- Lead engineer: domain model, PostgreSQL schema, API contracts and backend architecture
- Covers patient records, appointments, consent management, MFA and user management

`Go` `PostgreSQL` `Redis` `Next.js` `TypeScript` `Alibaba Cloud`

### 📊 Clarity Books
Multi-tenant cloud accounting SaaS for East African SMEs.
- Double-entry bookkeeping, PAYE, multi-warehouse inventory (FIFO / weighted average) and fixed assets with automated depreciation
- Direct integration with KRA eTIMS (OSCU) for tax-compliant invoicing

`SvelteKit` `Supabase` `PostgreSQL`

### 🛒 [GizmoJunction](https://www.gizmojunction.com/) · *Live*
E-commerce and retail ERP for the Kenyan market.
- eTIMS-compliant invoicing and M-Pesa checkout
- AI product categorisation with Gemini on Supabase Edge Functions
- Catalogue feed sync to Google Merchant Center and Jumia

`SvelteKit` `Supabase` `Edge Functions` `Gemini API`

### 🚚 Shukisha · *TransitNode*
Transit and parcel delivery platform.
- Event-driven backend with high-volume GPS telemetry in TimescaleDB
- M-Pesa B2C driver payouts and an IFRS 15-compliant ledger with immutable journal entries

`Go` `NATS / Kafka` `TimescaleDB` `PostgreSQL`

### ✈️ [AirLogix](https://github.com/okwama/airlogix-android)
Private aviation and cargo booking platform, with a native Android ground-handling app.

`Flutter` `Kotlin` `Jetpack Compose` `SvelteKit` `PHP`

### 📦 Belmur Freight Logistics
Freight forwarding platform for East African perishables: public site, operations admin and a REST API with 60+ endpoints.

`SvelteKit` `PHP 8.2` `MySQL` `REST API`

### 🧩 DevNexus · *TransitNode*
Local-first daemon that compresses codebase context into structured packets for AI coding tools like Claude Code and Cursor.
